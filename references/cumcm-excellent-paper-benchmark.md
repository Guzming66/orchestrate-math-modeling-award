## 可迁移的证据组织模式

对 2025 官方展示论文、`mathmodel-skill` 已归档样本，以及用户提供的 2022--2025 年 47 篇优秀论文作结构观察。用户语料的 47 篇共 2379 页已逐页原生提取/OCR，并完成 47/47 源文件与合并文本哈希核验；每篇另抽取摘要、正文中部、正文末端和支撑区关键页，共 188 页视觉核验。完整计数与 OCR 限制见 [cumcm-corpus-evidence-2022-2025.md](cumcm-corpus-evidence-2022-2025.md)。可稳定使用的不是“模型名称”，而是以下证据组织方式：

1. **摘要是一页结果地图**：逐问给出所用方法、可核验数值、单位/参照和主要验证；关键词具体指向对象与方法。
2. **先说明问题关系**：用短文或确有必要的一张关系图说明子问之间的参数、数据和决策依赖；没有分支或复杂接口时不画装饰性技术路线。
3. **每问形成闭环**：问题分析 → 变量/假设 → 模型 → 求解 → 结果 → 现实解释 → 验证或边界。
4. **模型公式可执行**：目标、约束和判定条件与代码一致；复杂算法前先给简单基线或小规模核验。
5. **图表各有证据职责**：展示几何关系、模型流程、核心结果、基线对比、诊断或稳健边界，不用图数充当质量。
6. **比较不只报最优值**：解释为何方案可行、相对基线改善多少、关键变量是否符合现实、不同算法是否给出一致结构。
7. **创新落在必要改动**：说明标准方法为何不足、改了哪个机制/约束、带来什么可复现收益和代价。
8. **局限性指向结论**：写清失效条件、受影响结论、所需新增数据或计算，而不是套话。

样本同时说明“常见”不等于“必要”：问题重述、独立符号章、模型优缺点清单、单独创新点和结论复述在展示论文中可以出现，但不能因为常见就机械保留。新版 CUMCM 模板只固定摘要、任务关系、建模基础和逐问闭环；其余章节按证据职责条件生成。

`$mathmodel-skill` 中 91 份来源文档、59 份可提取样本的分位数只能用于发现异常；不要把摘要字数、图表数、公式数或文献数变成配额或奖项预测。

## 建立标杆卡

按任务族而不是题号选论文。每种拟训练的任务族选择至少两篇来自不同年份或题号的展示论文，再配一份组委会赛题讲评。

在 `audits/benchmark/excellent_paper_review.md` 记录：

- 来源 URL、年份、题号、页面版权提示和访问日期；
- 论文解决的数学任务，不复制其具体答案；
- 摘要怎样对应子问、方法、数值、验证和边界；
- 每幅关键图表承担什么证据职责；
- 基线、诊断、敏感性和独立验证怎样安排；
- 哪些结构可迁移，哪些内容只属于原题；
- 一条值得保留的审计问题，而不是可复制句子。

不要把展示论文直接放入参赛工作区的共享目录。只把去题目化的结构卡放入 `shared/`，防止分支被具体解法锚定。

## 摘要终审

对摘要的每个子问执行前四项核对，并对全文最重要的风险执行第五项：

1. 写出真实任务和关键约束；
2. 写出实际使用的方法及其职责；
3. 给出至少一个可追溯结果，带单位或比较基线；
4. 指向验证、误差或稳健性证据；
5. 摘要整体说明一个会影响结论的失效条件或适用边界；
6. 与正文、结果文件、图表和代码版本一致。

摘要第一页只保留最重要的信息。不要写公式推导、长背景、空泛创新词、未运行的预期结果或展示论文的原句。

## 30 秒盲审

让未参与写作的审计任务只看摘要页和问题关系图，回答：

- 论文到底解决了什么；
- 每问用了什么且为什么；
- 三个最重要的数值结论是什么；
- 有什么证据说明结果可信；
- 最大风险或边界是什么。

若无法准确回答，修摘要与总路线图，不通过增加模型名称或形容词补救。

## 全文标杆矩阵

用 `present / partial / absent / not_applicable` 记录，不机械计总分：

| 维度 | 通过条件 |
|---|---|
| 题意闭环 | 所有子问有明确输入、输出、约束和结果 |
| 假设依据 | 关键假设来自题意、数据、机理或已核验文献 |
| 模型必要性 | 每个组件解决明确困难，复杂度带来可复现收益 |
| 基线 | 有公平可比的简单方案或解释为何无合理基线 |
| 验证 | 方法匹配模型风险，避免只做装饰性敏感性分析 |
| 结果解释 | 数字回到物理、业务或决策语义，量纲和数量级合理 |
| 图表职责 | 每幅图表支持一个明确论点且最终尺寸可读 |
| 上游误差 | 子问依赖与误差传播可追踪 |
| 局限与推广 | 写触发条件、受影响结论和重新标定步骤 |
| 复现 | 摘要数字、正文、生成表、代码和支撑材料一致 |
| 合规 | 匿名、引用、AI、页数、格式与附件全部通过 |

## 禁止误用

- 不复制展示论文的句子、图形布局、模型名称或代码。
- 不因为展示论文用了某算法就把它设为当届默认模型。
- 不把单篇论文或 59 份可提取子集的统计解释为官方评分标准。
- 不以“像优秀论文”覆盖题意偏差、结果错误、不可复现或违规。
